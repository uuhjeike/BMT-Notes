# BMT Notes

হোমওয়ার্ক, ক্লাসওয়ার্ক আর নোট শেয়ার করার জন্য একটা হালকা (lightweight), দ্রুত লোড হওয়া স্ট্যাটিক ওয়েবসাইট। কোনো ব্যাকএন্ড/ডাটাবেস নেই, কোনো ভারী এফেক্ট নেই — শুধু **টেক্সট ফাইলে লিখলেই** পোস্ট সাইটে চলে আসে।

## ফাইল স্ট্রাকচার

```
index.html        মূল পেজ
style.css         ডিজাইন (হালকা, কোনো blur/particle নেই)
script.js         বিষয়ের তালিকা + টেক্সট ফাইল পার্স করার লজিক
data/
  বাংলা-১.txt
  ইংরেজি-১.txt
  কম্পিউটার অফিস অ্যাপ্লিকেশন-১.txt
  ব্যবসায় গণিত ও পরিসংখ্যান.txt
  হিসাববিজ্ঞান নীতি ও প্রয়োগ-১.txt
  অর্থনীতি ও বাণিজ্যিক ভূগোল.txt
  ব্যবসায় সংগঠন ও ব্যবস্থাপনা-১.txt
  মার্কেটিং নীতি ও প্রয়োগ-১.txt
  ডিজিটাল টেকনোলজি ইন বিজনেস-১.txt
  হিউম্যান রিসোর্স ম্যানেজমেন্ট-১.txt
```

প্রতিটা বিষয়ের ফাইলের নাম হুবহু সেই বিষয়ের নামের মতো — নতুন করে মনে রাখতে হবে না।

## নতুন পোস্ট যোগ করা

সংশ্লিষ্ট বিষয়ের `.txt` ফাইল খুলে **ফাইলের একদম উপরে** একটা নতুন ব্লক বসাও (নতুন পোস্ট সবচেয়ে আগে দেখাবে)। প্রতিটা পোস্ট `-` লাইন দিয়ে আলাদা হয়:

```
-
DATE: ১৫ জানুয়ারি ২০২৬
এখানে হোমওয়ার্ক বা নোটের লেখা — একাধিক লাইন লেখা যায়।
IMG: https://.../photo1.jpg
IMG: https://.../photo2.jpg
-
DATE: ১৪ জানুয়ারি ২০২৬
শুধু লেখা পোস্ট, কোনো মিডিয়া ছাড়াই।
-
```

### সাপোর্টেড ট্যাগ

| ট্যাগ | কী করে |
|---|---|
| `DATE: ...` | পোস্টের তারিখ (দিলে সেই তারিখ অনুযায়ী সাজে; না দিলে সবচেয়ে নতুন-যোগ-করা পোস্ট উপরে থাকে) |
| `IMG: url` | ছবি — একাধিকবার দিলে গ্যালারি |
| `VID: url` | ভিডিও — একাধিকবার দিলে গ্যালারি |
| `AUD: url` | অডিও ক্লিপ |
| `DRIVE: url (নাম)` | গুগল ড্রাইভ ফাইলের বাটন |
| `LINK: url (নাম)` | যেকোনো লিংকের বাটন |

- ট্যাগ ছাড়া লাইন সাধারণ লেখা হিসেবে দেখাবে।
- `#` দিয়ে শুরু লাইন কমেন্ট — সাইটে দেখাবে না।
- টেক্সট-শুধু, এক/একাধিক ছবি, এক/একাধিক ভিডিও, অডিও — যেকোনো কম্বিনেশন একসাথে চলবে।
- ছবি/ভিডিওতে ক্লিক করলে বড় করে (লাইটবক্সে) খোলে; অডিওতেও একই রকম ক্লিক-টু-প্লে।
- মিডিয়া ফাইল অন্য কোথাও হোস্ট থাকতে হবে (যেমন GitHub-এ আপলোড করে raw লিংক ব্যবহার করা)।

## লোকালি দেখা

সরাসরি `index.html` ডাবল-ক্লিক করলে টেক্সট ফাইল লোড নাও হতে পারে (CORS)। তাই ফোল্ডারে টার্মিনাল খুলে:
```
python3 -m http.server 8000
```
তারপর ব্রাউজারে `http://localhost:8000` খোলো।

## GitHub Pages-এ পাবলিশ করা

1. GitHub-এ একটা রিপো বানাও।
2. এই সব ফাইল/ফোল্ডার আপলোড করো।
3. Settings → Pages-এ branch `main`, folder `/root` সিলেক্ট করে Save করো।
4. `https://<username>.github.io/<repo>/` এ সাইট লাইভ হয়ে যাবে।
5. এরপর শুধু `.txt` ফাইল এডিট করে কমিট করলেই নতুন পোস্ট চলে আসবে।
